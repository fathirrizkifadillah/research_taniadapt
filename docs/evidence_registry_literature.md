# Evidence registry for the decision engine

**Status:** DRAFT. This registry separates sources that were opened and checked from sources that remain unavailable or insufficiently specific. Only `VERIFIED` IDs can appear in a rule that produces an agronomic status or action. Every other ID must yield `evidence_insufficient`.

The machine-readable source of truth is `reports/dataset_audit/evidence_registry.csv`, generated by `scripts/build_evidence_registry.py`.

## Verified entries available now

| Evidence ID | Commodity | Operationally limited use | Source checked |
|---|---|---|---|
| `FAO56_ET0_PM` | all | FAO-56 reference ET0 method, after independent code validation | Allen et al. (1998), FAO-56, Equation 6 / Chapter 2 |
| `FAO56_KC_RICE` | padi | ETc reference calculation only | FAO-56 Table 12, p. 110 |
| `FAO56_KC_MAIZE` | jagung | ETc reference calculation only | FAO-56 Table 12, p. 110 |
| `FAO56_KC_SOY` | kedelai | ETc reference calculation only | FAO-56 Table 12, p. 110 |
| `FAO56_KC_TOMATO` | tomat | ETc reference calculation only | FAO-56 Table 12, p. 110 |

FAO-56 Table 12 concerns non-stressed, well-managed crops under stated subhumid standard conditions. Its values are not a local yield-loss threshold, planting calendar, disease rule, or action recommendation. The table does not automatically establish a rule for Indonesian cabai simply because it includes bell pepper.

## Entries deliberately not activated

- Base, optimum, and maximum temperatures by phase for padi, jagung, and kedelai: `UNVERIFIED`. No number is loaded into GDD or a thermal-status rule.
- Soybean water coefficients: `UNVERIFIED` in the present single-Kc registry.
- Cabai antraknosa and tomato late-blight conducive-weather proxies: `CANNOT_OPEN` for a paper that supplies an exact, engine-ready definition of leaf wetness/RH/hours and temperature. No literal humidity, temperature, or wetness threshold is used.
- All action IDs: `CANNOT_OPEN` pending an opened official extension source from Kementan, BPTP/BRMP, Balitsa, or Litbang. This includes `ACT_FUNGICIDE_REVIEW`.

## Rule for additions

For each new source, record the crop species, full citation, stable DOI/URL, exact page or table, study location, how the weather proxy was defined, and the condition under which its parameter applies. A source that cannot be opened is stored as `CANNOT_OPEN`; a source that is open but cannot support the intended transfer is `UNVERIFIED`. Neither status authorizes a threshold or action.
